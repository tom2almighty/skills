## 1. 空间分组与动效

- **接近性原则**：组内紧、组间松。例如 label 与 input 用 `gap-1`~`gap-1.5`，字段组之间用 `gap-4`~`gap-6`，必要时加 `Separator`。用留白而不是多层边框表达归属。
- **动效**（建议）：微交互（hover、选中指示、折叠展开）用 150–200ms 的 ease-out CSS 过渡；Tab 切换、弹窗/抽屉显隐用淡入淡出或极小位移。默认不引入动画库；仓库已有 `motion` 等库时可用于组内高频微交互的弹性效果。避免大面积弹跳。

## 2. 选择器与筛选

| 选项数量 | 控件 |
|---|---|
| ≤ 5 且互斥 | `RadioGroup`、分段控制器或平铺 Tag |
| 6–8 | 普通 `Select` |
| > 8 | 可搜索的 `Combobox` / `Command` |

- 多条件筛选：高频条件外露，低频收进"更多筛选"（Popover/Drawer）。
- 有激活的筛选条件时提供一键重置，并让激活状态可见（如数量徽标）。

## 3. 操作层级与危险操作

- **渐进披露**：同一视觉区域（工具栏、卡片角、表格行）只保留 1 个 Primary 按钮，高频次要操作外露不超过 2 个，其余收进 `DropdownMenu`。
- **危险操作**（硬约束）：
  - 使用 `destructive` 语义样式，并与常规操作在位置上隔离。
  - 必须经 `AlertDialog` 二次确认，文案说明后果。
  - **需输入目标名称确认的标准**：不可恢复且影响范围大的操作，如删除项目/工作区、清空数据、解绑账号、撤销密钥。单条记录的可恢复删除只需二次确认。
- 表单有未保存修改时，关闭弹窗/抽屉要拦截并确认。

## 4. 悬浮二级浮层

- 级联菜单与 Hover 卡片优先用 Radix 原生组件（`DropdownMenuSub`、`HoverCard`、`NavigationMenu`），它们已处理斜向移动。
- 自定义 hover 浮层必须处理斜向移动误关闭：三角安全热区，或不可见的指针桥接 + 100–150ms 退出宽限。
- 触屏与键盘用户无法 hover：关键信息和操作必须同时支持 click/focus 触发。

## 5. 空 / 加载 / 失败态与防抖动

- 空状态：图标 + 功能说明 + 引导操作。
- 加载态：优先用与真实布局高度匹配的 `Skeleton`。
- 失败态：在出错区块内展示可读错误和重试按钮，不整页报错。
- 防页面跳动：图片与异步区块预设固定高度或 `aspect-*`；全局设置 `scrollbar-gutter: stable`。

## 6. 文本、弹窗与窄屏

- 长标题、路径、用户名用 `truncate` / `line-clamp-*`，并用 `Tooltip` 展示原文。
- 表格中的数字、金额、时间戳用 `tabular-nums`。
- `Dialog` / `Sheet` 内容过长时固定 Header/Footer，中间区域 `overflow-y-auto`，避免双重滚动条。
- 窄屏下侧边栏收起为抽屉；表单支持回车提交，浮层支持 `Esc` 关闭。
